# Исследование категории "Swiss Army Knife for Developers" (DevToys, CyberChef, He3)

## 1. Обзор категории и ландшафт существующих решений

В последние годы сформировался отдельный класс ПО — **десктопные мультитулы для разработчиков** (Developer Swiss Army Knives). Исторически программисты пользовались разрозненными онлайн-сервисами (jwt.io, jsonformatter.org, regex101.com, crontab.guru, base64decode.org). Однако рост требований к информационной безопасности, появление строгих корпоративных политик (NDA, SOC2, GDPR, HIPAA) и желание иметь мгновенный отклик привели к взрывному росту оффлайн-комбайнов.

### Ключевые представители рынка:

| Продукт | Платформа | Архитектура / Стек | Сильные стороны | Слабые стороны |
| :--- | :--- | :--- | :--- | :--- |
| **DevToys** | Windows / macOS / Linux (DevToys 2.0) | C# / .NET MAUI / Blazor | Быстрый, нативный UI Windows Fluent, богатый набор утилит, поддержка плагинов, CLI-версия. | Долгая разработка v2.0, потребление памяти при тяжелых задачах. |
| **CyberChef** (GCHQ) | Web / Offline HTML | Pure JavaScript / WebAssembly | Исключительная мощь конвейерной обработки (Pipelines / Recipes), сотни криптографических и форензик-операций. | Сложный для новичков интерфейс, ориентирован больше на security/CTF/forensics, чем на ежедневный web/backend dev. |
| **DevUtils** | macOS | Swift / SwiftUI (Native) | Быстрый нативный интерфейс, автоматическое определение содержимого буфера обмена (Smart Clipboard), zero-latency. | Закрытый исходный код, только macOS, платная лицензия. |
| **He3** | Windows / macOS / Linux | Electron / Web | Более 200+ микро-утилит, умный поиск (Cmd+K), современный UI. | Проприетарный, тяжеловесный Electron (высокое потребление ОЗУ), фоновая телеметрия. |
| **IT-Tools** | Web / Docker (Self-hosted) | Vue 3 / Nuxt / TypeScript | Красивый интерфейс, открытый код (open-source), удобная категоризация, легко развернуть в корпоративном интранете. | Изначально веб-приложение, нет системной интеграции (горячие клавиши ОС, трей, работа без браузера). |

## 2. Почему разработчики уходят от онлайн-сервисов в оффлайн-приложения

1. **Безопасность и конфиденциальность (Zero Data Leakage)**:
   - Вставка production-токенов JWT, клиентских JSON-дампов, приватных RSA-ключей или хешей паролей на публичные сайты влечет за собой риски утечки данных в сторонние логи, Cloudflare-прокси и CDN.
   - Многие компании на уровне DLP (Data Loss Prevention) и прокси блокируют сайты типа `pastebin`, `jwt.io` или `jsoneditoronline`.
2. **Нулевая задержка (Instant Launch & Zero Latency)**:
   - Десктопный инструмент вызывается по глобальной горячей клавише (например, `Alt+Space` или клик в трее) за 100 мс без ожидания DNS, загрузки тяжелых рекламных баннеров и всплывающих cookie-согласий.
3. **Работа в закрытых контурах и оффлайн**:
   - Работа в перелетах, поездках, на защищенных контурах (VPC/VPN без выхода в открытый интернет) или изолированных средах разработчиков.
4. **Эргономика единого рабочего пространства**:
   - Вместо 15 открытых вкладок браузера — один унифицированный интерфейс с моноширинными шрифтами, темной темой, горячими клавишами и мгновенным копированием результата в один клик.

## 3. Частотность использования инструментов: Рейтинг ежедневных операций

По данным сообществ разработчиков (GitHub, Reddit r/programming, Hacker News), ежедневные микро-задачи инженеров распределяются по частотности следующим образом:

1. **Работа со структурами данных (JSON / YAML / TOML / XML)**:
   - 80% времени backend-, frontend- и devops-инженеров связано с форматированием JSON-ответов API, валидацией синтаксиса и конвертацией между форматами (JSON <-> YAML для Kubernetes, Docker Compose, GitHub Actions, OpenAPI).
2. **Аутентификация и безопасность (JWT Tokens)**:
   - Декодирование и верификация сроков действия access/refresh токенов (exp, nbf, iat), проверка утверждений (claims), проверка подписи по HMAC secret или RSA/ECDSA public key.
3. **Энкодинг и экранирование строк (Base64, URL, HTML Entities)**:
   - Раскодирование query-параметров в URL, Base64-авторизационных заголовков (`Basic ...`), Data-URL картинок, преобразование спецсимволов.
4. **Отладка регулярных выражений (Regex)**:
   - Проверка шаблонов валидации email, телефонов, slug-ов, парсинга логов с моментальной визуализацией групп захвата (capturing groups).
5. **Временные метки и расписания (Unix Epoch & Cron)**:
   - Преобразование миллисекунд/секунд эпохи в локальное время и UTC; генерация и расшифровка cron-выражений для crontab/k8s/Celery.
6. **Генераторы идентификаторов и хешей (UUID v4/v7, SHA-256, MD5)**:
   - Быстрая генерация мок-данных для БД и тестов, проверка контрольных сумм.
7. **Текстовые диффы (Text & JSON Diff)**:
   - Сравнение двух конфигов, ответов API до/после изменений.

## 4. ТОП-5 незаменимых утилит для интеграции в ToolHub

Для того чтобы сделать **ToolHub** незаменимым ежедневным комбайном разработчика на рабочем столе, выделены 5 базовых утилит с максимальным коэффициентом полезности и частоты использования.

---

### ТОП-1: Universal JSON & YAML Studio (Formatter, Validator, Bi-directional Converter)
*Частота использования: 10–25 раз в день.*

* **Назначение**:
  Мгновенное форматирование ("Pretty Print"), минификация, проверка синтаксиса и конвертация между JSON, YAML и TOML.
* **Ключевой функционал**:
  - Двухпанельный редактор с подсветкой синтаксиса и номерами строк.
  - Мгновенная валидация синтаксиса в реальном времени с точным указанием строки и столбца ошибки (подсветка места сбоя красным маркером).
  - Кнопки быстрых действий: `Prettify (2/4 spaces)`, `Minify / Compact`, `Sort Keys alphabetically`, `Fix Common Quotes / Trailing Commas`.
  - Двусторонняя конвертация: JSON ⇄ YAML ⇄ TOML в один клик.
  - Поиск по ключам и поддержка фильтрации по **JSONPath** (например, `$.data.items[*].id`).
* **Почему это киллер-фича для ToolHub**:
  Каждый веб-разработчик сталкивается с огромными неформатированными логами или JSON-ответами. Возможность вставить грязный JSON и мгновенно получить чистый отсортированный результат оффлайн — базовая необходимость.

---

### ТОП-2: JWT Security Inspector & Token Debugger
*Частота использования: 5–15 раз в день.*

* **Назначение**:
  Полная оффлайн-инспекция JWT-токенов без отправки секретов в интернет.
* **Ключевой функционал**:
  - Трехцветное разделение структуры токена: **Header** (розовый), **Payload** (фиолетовый), **Signature** (голубой).
  - Автоматический парсинг дат: поля `exp` (истечение), `iat` (выпуск), `nbf` (не ранее чем) отображаются в виде понятного человекочитаемого статуса:
    - Зеленый бейдж: `Действителен (осталось 42 мин 15 сек)`.
    - Красный бейдж: `Истек 3 часа назад (06.11.2026 19:04:12 UTC)`.
  - Оффлайн-валидатор подписи: ввод Secret / Public Key (HMAC HS256/384/512, RSA RS256, ECDSA ES256) с вердиктом: "Подпись верна" или "Подпись не совпадает".
  - Копирование очищенного JSON плейлоуда в один клик.
* **Почему это киллер-фича для ToolHub**:
  Использование публичного `jwt.io` для корпоративных или боевых токенов — грубое нарушение безопасности. Оффлайн-декодер в ToolHub решает проблему приватности раз и навсегда.

---

### ТОП-3: Smart Multi-Encoder & Decoder (Base64, URL, HTML, Hex)
*Частота использования: 10–20 раз в день.*

* **Назначение**:
  Универсальная швейцарская машина для преобразования строк и бинарных данных между всеми популярными схемами кодирования.
* **Ключевой функционал**:
  - Режимы в одном окне с мгновенным переключением:
    1. **Base64**: Text ⇄ Base64, Base64 URL-safe, Image/File ⇄ Data-URI (с превью изображения).
    2. **URL**: Encode / Decode (компоненты URL `encodeURIComponent` и полные адреса).
    3. **HTML Entities**: Экранирование и деэкранирование (`&`, `<`, `>`, `"`, `'`).
    4. **Hex / ASCII / Binary**: Преобразование байтов и шестнадцатеричных последовательностей.
  - Опция **Smart Detect**: автоопределение типа входных данных (если вставлена строка, похожая на Base64 или URL-encoded, утилита сразу предлагает правильное действие).
  - Двустороннее редактирование в реальном времени (ввод слева -> результат справа, кнопка Swap для инверсии).
* **Почему это киллер-фича для ToolHub**:
  Устраняет необходимость держать 4 отдельных вкладки браузера для базовых операций кодирования.

---

### ТОП-4: Interactive Regex Engine & Tester (PCRE / JavaScript / Python)
*Частота использования: 3–10 раз в день.*

* **Назначение**:
  Интерактивная отладка регулярных выражений с визуализацией совпадений и групп захвата в реальном времени.
* **Ключевой функционал**:
  - Поле ввода регулярного выражения с тумблерами флагов: `g` (глобальный), `i` (регистронезависимый), `m` (многострочный), `s` (dotAll).
  - Поле тестового текста с моментальной цветовой подсветкой найденных совпадений.
  - Таблица разобранных групп захвата (**Capture Groups**): имя/номер группы, диапазон символов, захваченное значение.
  - Режим замены (**Regex Replace**): строка шаблона замены (с поддержкой `$1`, `$2`) и окно итогового текста.
  - Библиотека встроенных популярных пресетов в один клик:
    - Email, IPv4/IPv6 адрес, URL, UUID, дата ISO 8601, номер телефона, синтаксис шестнадцатеричного цвета.
* **Почему это киллер-фича для ToolHub**:
  Заменяет тяжелый веб-сайт `regex101`, исключает риск зависания браузера при Catastrophic Backtracking и работает без подключения к сети.

---

### ТОП-5: Unix Epoch & Cron Schedule Calculator
*Частота использования: 5–10 раз в день.*

* **Назначение**:
  Единый пульт для работы с системным временем и планировщиками задач.
* **Ключевой функционал**:
  - **Блок Unix Timestamp**:
    - Текущий Timestamp в секундах и миллисекундах (живой таймер).
    - Двусторонняя конвертация: Timestamp ⇄ Человекочитаемая дата (Local Timezone и UTC).
    - Относительное время: "2 часа назад", "через 5 дней".
    - Быстрый выбор форматов: ISO 8601, RFC 2822, SQL DateTime, Unix epoch.
  - **Блок Cron Calculator**:
    - Ввод 5- или 6-позиционного cron-выражения (например, `*/15 9-18 * * 1-5`).
    - Человекочитаемая расшифровка на русском/английском языке ("Каждые 15 минут, с 09:00 до 18:59, с понедельника по пятницу").
    - Калькулятор следующих запусков: расчет и вывод точного списка следующих 10 дат и времени выполнения задачи.
* **Почему это киллер-фича для ToolHub**:
  Ошибки в cron-выражениях регулярно приводят к сбоям в продакшене. Наличие мгновенного оффлайн-валидатора дат и cron-таймеров предотвращает фатальные ошибки конфигурации.

## 5. Бонусные утилиты второй очереди (High Priority Runners-up)

После внедрения базового ТОП-5 рекомендуется добавить следующие инструменты:

1. **UUID & Hash Generator Studio**:
   - Генерация UUID v4 (криптографически стойкий random) и современного **UUID v7** (time-ordered, критически важный для первичных ключей современных БД).
   - Мгновенный расчет хешей текста и файлов: MD5, SHA-1, SHA-256, SHA-512, CRC32, HMAC с секретом.
2. **Side-by-Side Diff Checker**:
   - Быстрое построчное и посимвольное сравнение двух фрагментов кода, текста или JSON с цветовой индикацией добавленных, удаленных и измененных строк.
3. **Color Studio & Asset Converter**:
   - HEX ⇄ RGB ⇄ HSL, превью цветов, конвертер SVG в PNG/Base64.

## 6. Рекомендации по UX/UI внедрению в архитектуру ToolHub

1. **Интеграция в дизайн-систему ToolHub (Obsidian Studio Palette)**:
   - Использование темной темы (`#09090b` canvas, `#0e0f12` surface, 1px бордеры `rgba(255,255,255,0.08)`).
   - Моноширинный шрифт `JetBrains Mono` / `Fira Code` для всех блоков кода и данных.
2. **Умный буфер обмена (Smart Clipboard Detection)**:
   - При переходе во вкладку или при нажатии кнопки "Вставить из буфера" ToolHub может автоматически определять тип содержимого:
     - Начинается на `eyJh...` -> JWT токен.
     - Начинается на `{` или `[` -> JSON.
     - Начинается на `http%3A%2F%2F` -> URL-encoded строка.
     - Число из 10 или 13 цифр -> Unix Timestamp.
3. **Микро-взаимодействия**:
   - Кнопка "Скопировать" (Copy) у каждого блока результата с всплывающим бейджем `Скопировано!` на 1.5 секунды.
   - Поддержка горячих клавиш: `Ctrl+Enter` (выполнить форматирование/запуск), `Ctrl+Shift+C` (скопировать результат), `Esc` (очистить поля).
4. **Оффлайн-обработка на клиенте**:
   - Все операции (JSON, JWT, Regex, Base64, Timestamp) выполняются локально в JS/WebAssembly или Python backend без единого сетевого запроса, гарантируя 100% приватность.
