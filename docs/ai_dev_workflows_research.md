## 1. Введение и ключевые тренды индустрии (2025–2026)

Разработка программного обеспечения переживает фундаментальный сдвиг: от простого автодополнения кода (эпоха GitHub Copilot 2022–2023) индустрия перешла к **автономным агентным воркфлоу (Agentic Workflows)** и **мультимодальным контекстным средам**.

### Ключевые тренды:
1. **Переход к AI-агентам прямого действия**:
   - Разработчики массово мигрируют на **Cursor** (с режимом Composer / Agent Mode), **Claude Code** (официальный консольный агент от Anthropic), **Windsurf** (Cascade Flows), а также open-source агентные движки: **Aider**, **Roo Code / Cline** (fork Claude Dev), **Goose** (Block) и **OpenHands**.
   - Агенты не просто подсказывают строчки кода: они выполняют shell-команды, читают файловую систему, запускают тесты, находят ошибки в логах и коммитят изменения.

2. **Стандартизация интеграций через MCP (Model Context Protocol)**:
   - Представленный Anthropic в конце 2024 года протокол MCP стал стандартом de-facto в 2025–2026 годах. Все ведущие клиенты (Claude Desktop, Cursor, Continue, Zed, Claude Code) внедрили нативную поддержку MCP.
   - Разработчики строят цепочки: LLM ↔ MCP Server (Local SQLite, PostgreSQL, Docker, Git, Brave Search, Filesystem) ↔ Production Environment.

3. **Проблема «Засорения контекста» и стоимости (Context Drift & Token Waste)**:
   - Хотя контекстные окна моделей выросли (до 200k у Claude 3.7 Sonnet и 1M+ у Gemini 2.5 Flash/Pro), передача «сырых» репозиториев приводит к деградации рассуждений («lost in the middle»), превышению лимитов (rate limits) и огромным финансовым затратам.
   - Появился новый класс утилит: **AI Context Distillers / Repo Packers**, упаковывающие только релевантный код без шума (lock-файлы, тесты, скомпилированные бинарники).

4. **Мульти-аккаунтинг, ротация ключей и приватность**:
   - Жесткие лимиты подписок (Claude Pro/Team 5-часовые ограничения, квоты Fast Requests в Cursor) заставляют разработчиков держать несколько профилей/аккаунтов или балансировать трафик через провайдеров вроде OpenRouter и локальные модели (Ollama, DeepSeek R1/V3).
   - Острая потребность в изоляции устройств (`machineID`, `userID`, чистка телеметрии) для предотвращения теневых банов и связывания аккаунтов.

## 3. ТОП-5 киллер-фичей для интеграции в ToolHub Studio

Наше десктопное приложение **ToolHub Studio** обладает мощной архитектурной базой:
- **Tauri / Python**: нативная скорость, нулевой оверхед по памяти, прямой доступ к Win32 API и файловой системе.
- **Obsidian Dark UI**: премиальный интерфейс для гиков и инженеров, интерактивные слайдеры, выдвижные логи.
- **Уже заложенные модули**: `claude_code` (сброс `machineID` и телеметрии), `mcp_api` (MCP endpoint), `system_specs` (мониторинг системы 0 ms).

Ниже представлены **ТОП-5 самых востребованных фичей**, которые идеально дополняют ToolHub Studio и превращают его в незаменимый швейцарский нож разработчика:

---

### Фича №1: AI Context & Repo Distiller (Генератор AI-контекста репозиториев)
> **Концепт:** Локальный визуальный аналог Repomix и Gitingest прямо в окне ToolHub Studio.

* **Ценность для пользователя:**
  Разработчик перетаскивает папку проекта (Drag & Drop) в ToolHub. Приложение мгновенно сканирует структуру, фильтрует мусор (`node_modules`, `.git`, `dist`, `package-lock.json`, бинарники, медиа), рассчитывает точное количество токенов (cl100k/o200k/Claude токенайзеры) и формирует оптимизированный для промпт-кэшинга файл контекста (`context.xml` или `context.md`).
* **Ключевые опции (в стиле ToolHub):**
  - Слайдер `Исключать тесты и моки` (`tests/`, `__tests__`, `*.spec.ts`).
  - Слайдер `Интеллектуальное сжатие кода` (удаление длинных комментариев, пустых строк).
  - Слайдер `Только сигнатуры и интерфейсы` (для крупных проектов: экспортирует структуру классов, типов и функций без тел реализаций).
  - Бейдж: подсчет общего количества токенов и ориентировочная стоимость в Claude 3.7 / GPT-4o.
* **Формат реализации в ToolHub Studio:**
  - **Frontend:** Зона Drag & Drop, дерево каталогов с чекбоксами включения/исключения, кнопка «Копировать для Claude / Cursor» (с тактильной анимацией).
  - **Backend (Python):** Модуль быстрого обхода файловой системы с поддержкой `.gitignore` и `.toolhubignore`, библиотека `tiktoken` / токенайзер для расчета объема.

---

### Фича №2: MCP Hub & Local Servers Manager (Центр управления и тестирования MCP)
> **Концепт:** Графический хаб для каталога, запуска, мониторинга и тестирования MCP-серверов в один клик.

* **Ценность для пользователя:**
  Сегодня разработчик тратит часы на ручное редактирование JSON-файлов:
  - `%APPDATA%\Claude\claude_desktop_config.json`
  - `.cursor/mcp.json`
  Если MCP-сервер (например, на Node.js или Python) упал — отлаживать его через стандартные клиенты крайне сложно.
  ToolHub Studio берет на себя роль **визуального шлюза**:
  - Каталог готовых пресетов в 1 клик: *Postgres, SQLite, Git Tools, Local Filesystem, Docker, Brave Search, Memory*.
  - Автоматическая синхронизация конфигов в Claude Desktop и Cursor (один переключатель активирует сервер сразу везде).
  - Встроенный интерактивный **Tool Tester**: вызов любого MCP-инструмента прямо из UI с просмотром JSON-ответа.
* **Формат реализации в ToolHub Studio:**
  - **Frontend:** Карточки серверов со статусами (Active / Stopped / Error), консоль логов вызовов в реальном времени, модальное окно тестирования параметров.
  - **Backend (Python):** Запуск и контроль фоновых дочерних процессов (`stdio`), валидация JSON-RPC 2.0, безопасная запись в конфигурационные файлы клиентов.

---

### Фича №3: Multi-Account & Claude Code Profile Switcher (Менеджер профилей и анти-привязки)
> **Концепт:** Развитие существующего модуля `claude_code` в полноценный диспетчер профилей и квот.

* **Ценность для пользователя:**
  Разработчики часто вынуждены жонглировать аккаунтами:
  1) Рабочий аккаунт (Team/Enterprise),
  2) Личный аккаунт (Claude Pro),
  3) Аккаунты для тестирования и обхода лимитов.
  Anthropic связывает клиентов по `machineID`, `userID` и телеметрии в `~/.claude/`.
  ToolHub Studio предлагает:
  - **Переключение профилей в 1 клик**: мгновенная подмена токенов, cookies и сессий.
  - **Генератор чистого отпечатка (Clean Device Identity)**: генерация нового `machineID` (SHA-256), `userID` (UUIDv4) и полная зачистка папки телеметрии `~/.claude/telemetry/`.
  - **Локальный аудит расходов**: разбор локальных логов сессий Claude Code — сколько токенов и денег потрачено за день/неделю.
* **Формат реализации в ToolHub Studio:**
  - **Frontend:** Переключатель профилей в верхней панели (`Work Profile`, `Personal`, `Sandbox`), индикатор «Устройство: Новое / Изолировано», счетчик сессий.
  - **Backend (Python):** Безопасный менеджер хранилища профилей в локальном зашифрованном файле, манипуляции с `~/.claude.json`.

---

### Фича №4: Smart Git AI Assistant & Diff Sanitizer (Генератор коммитов и очиститель диффов)
> **Концепт:** Автоматизация осмысленных Conventional Commits и очистка диффов перед отправкой в AI.

* **Ценность для пользователя:**
  - **Проблема 1:** Разработчики тратят время на выдумывание описаний коммитов или пишут бессмысленные `fix`, `update`, `test1`.
  - **Проблема 2:** При отправке диффа в AI для код-ревью или PR-описания в контекст улетает гигантский мусор (изменения пробелов, автоформатирование Prettier/Black, 10 000 строк `package-lock.json`).
  ToolHub Studio:
  1) Считывает `git diff --cached` выбранного репозитория.
  2) Вырезает шум: удаляет whitespace-only диффы, сжимает лок-файлы до одной строчки.
  3) Генерирует 3 варианта структурированных коммитов по стандарту Conventional Commits с эмодзи (например: `feat(auth): add OAuth2 refresh token rotation`).
  4) Поддерживает как локальный запуск (через Ollama / DeepSeek R1 — без отправки приватного кода в сеть), так и через API-ключи.
* **Формат реализации в ToolHub Studio:**
  - **Frontend:** Предпросмотр диффа с красивой подсветкой (до/после), выбор варианта коммита, кнопка `Commit & Push` в 1 клик.
  - **Backend (Python):** Вызов локального Git через `subprocess`, модуль фильтрации диффа, интеграция с Ollama (локальный порт `11434`) или внешним API.

---

### Фича №5: Prompt Forge & Rules Repository (`.cursorrules` & `CLAUDE.md`)
> **Концепт:** Интерактивная библиотека проверенных правил и системных инструкций для AI-ассистентов.

* **Ценность для пользователя:**
  Качество работы Cursor, Windsurf и Claude Code на 80% зависит от файла правил проекта (`.cursorrules`, `CLAUDE.md`, `.windsurfrules`). Сейчас разработчики вручную ищут их на форумах или GitHub.
  ToolHub Studio предоставляет:
  - **Встроенную галерею протестированных правил**:
    - *Fullstack:* Next.js App Router + Tailwind + Prisma;
    - *Backend:* Python FastAPI + SQLAlchemy 2.0 + Pydantic v2;
    - *Systems:* Rust + Tokio + Axum;
    - *Quality:* Clean Code, TDD, Strict TypeScript, Anti-Hallucination Guardrails.
  - **Мастер настройки**: выбор стека переключателями (слайдерами) → автоматическая сборка идеального файла правил.
  - **Развертывание в 1 клик**: кнопка «Записать в проект» (создает `.cursorrules` или `CLAUDE.md` прямо в корне выбранной папки).
* **Формат реализации в ToolHub Studio:**
  - **Frontend:** Карточки категорий в стиле Obsidian, окно редактирования Markdown с подсветкой синтаксиса, кнопка развертывания в проект.
  - **Backend (Python):** База данных готовых шаблонов, генератор конфигураций по параметрам.
